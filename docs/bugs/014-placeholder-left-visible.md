# 014　打几个字后正文公式变成 `%%M:…%%`

**状态：** 0.1.25 输入结束后仍把占位符画回 KaTeX  
**报告人：** 用户（2026-09-17）  
**出现版本：** 0.1.24  
**文件：** `main-revised-zh.md` 摘要。源码仍是 `$K_1$` 等，未写坏。

## 现象

摘要末尾输入「测试一下」后，中间的 $K_1$、$K_2$、$J$ 在渲染窗里变成 `%M:…%%` 乱码。

## 原因

Lute `SpinVditorDOM` 先把公式收成 `%%M:` 占位符，再靠 leftover 画回 KaTeX。0.1.24 为躲输入法，光标所在段一直跳过 leftover。字打完占位符也不再画。

## 处理

只在输入法进行中跳过当前段。输入结束后整段重画占位符。顺带认 `%M:…%%`（少一个 `%`）。
