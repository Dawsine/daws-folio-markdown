# 009　粘贴公式变成 C / V / n 分行

**状态：** 0.1.15 复制写回 `$...$`，粘贴按公式插入，写盘清 KaTeX HTML  
**报告人：** 用户（2026-09-15）

## 现象

正文和表格里粘贴 `$C_{V_n}$` 一类公式，保存后变成

```
C

V

n
```

## 原因

复制渲染好的 KaTeX 时，`getSelection().toString()` 把 `inline-table` 竖排读成换行。再粘贴就把分行写进文件。写回时 Lute 也把没包好的 `.katex` HTML 拆成字。

## 处理

复制从公式节点取 TeX，剪贴板写 `$...$`。粘贴拦 HTML，按 `$...$` 插成公式块。写盘前把漏出的 KaTeX / MathML 收成 `$...$`。
