# 006　Folio 开着时，截图粘不进对话框

**状态：** 0.1.9 只有 Folio 自己在输入时才接管 Cmd+V  
**报告人：** 用户（2026-09-14）

## 现象

截图后往对话框里粘贴，图片进不去。把 Markdown 关掉就能贴。

## 原因

0.1.7 为了让 Folio 里剪切可用，把 Cmd+V 绑在「Folio 标签还开着」。对话框有焦点时快捷键仍进 Folio。剪贴板是图，Folio 只读文字，等于把这一下吃掉了。

## 处理

剪切/复制/粘贴的 when 加上 `!inputFocus && !textInputFocus`：对话框、输入框聚焦时不抢。
