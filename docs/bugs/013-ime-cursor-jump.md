# 013　输入法打到一半就被渲染，光标跳回段首

**状态：** 0.1.24 源码窗打字不再整篇写回；输入法未结束不跑公式重绘  
**报告人：** 用户（2026-09-17）  
**出现版本：** 0.1.23，长稿双开时  

## 现象

源码里打「他的固有条件」。「固有」确认后，渲染窗立刻重画；拼音还在输入法里时也被画上去。字确认完，光标跳到这段开头，「条件」要重新点回去打。整篇也极慢。

## 原因

1. 源码每改一次，Folio 立刻 `setValue` 整篇，Vditor 再 `getValue` 写回整个 TextDocument。源码光标跟着整篇替换跑掉。
2. 输入法 `composition` 期间，公式 MutationObserver 仍扫全文并改 DOM。
3. 2500 行稿每次击键都走一遍 leftover KaTeX。

## 处理

- Folio 未聚焦时只防抖预览，不写回。
- 自己 `applyEdit` 时打 `writing`，不再回推 `update`。
- `compositionstart` 到结束后约 80ms：不保存、不重绘公式、不 `setValue`。
- leftover 只在突变里像公式时才跑；正在打的段落先跳过。
