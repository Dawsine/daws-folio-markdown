# 011　一改正文，独立公式和下一段粘成 `$$$`

**状态：** 0.1.17 写盘时把 `$$…$$$$\Pi$` 拆开  
**报告人：** 用户（2026-09-15）

## 现象

报告第 2 章只改了一点说明，保存后整页挤成一段，KaTeX 报 `Can't use function '$' in math mode`。源文件变成

```
$$Y_{\mathrm{calc}}=\Pi\circ S(\ldots)$$$$\Pi$ 是与实验共用的观测定义
```

## 原因

Vditor `getValue()` 把多行

```
$$
公式
$$

$\Pi$ …
```

收成一行，`$$` 和下一段的 `$` 连成 `$$$`。

## 处理

写盘前（`restoreMathInTables`）把 `$$…$$` 后面紧贴的非空白拆开，围成独立公式块。围栏代码不动。
