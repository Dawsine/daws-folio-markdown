# 008　表格格子里的 `<br>` 当字印出来

**状态：** 0.1.14 格子里的 `<br>` 画成换行，写回仍是 `<br>`  
**报告人：** 用户（2026-09-15）

## 现象

`| a<br>b |` 在 Folio 里看见字面量 `<br>`，GitHub / 自带预览是换行。

## 原因

Vditor 默认 `sanitize`，Lute 把格子里的 HTML 当文本。GFM 表格又不能用真换行，只能写 `<br>`。

## 处理

和表格公式同一条路：进编辑器前把格子里的 `<br>` / `<br/>` 收成 `%%BR%%`（行内代码里的不动），画成真换行；`getValue` 再写回 `<br>`。
